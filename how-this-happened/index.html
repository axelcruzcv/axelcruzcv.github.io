SIX DISCIPLINES. ONE PRODUCT.

HOW THIS HAPPENED.

You can read the work in 90 seconds. Or open the mechanics behind each decision. Both paths tell the same story.

01 / PRODUCT

THE QUESTION.

How do you show complex professional experience without asking someone to read everything? Start with the visitor's problem. Not a list of your skills.

Explore the mechanics ↗

Audience: recruiters, hiring managers, operations leaders and technical reviewers. Primary action: choose a professional focus. Scope: one-screen discovery; optional deeper routes. Success signals: lens interaction, relevant case opening and CV navigation.

02 / EXPERIENCE

THE PATH.

The first screen gives you one choice, then one reason to believe. Three main exits lead to real work, working style and the CV. No forced tour.

Explore the mechanics ↗

Accessible buttons use aria-pressed, a live-updating evidence region and keyboard focus states. Responsive CSS makes the experience one screen on larger displays while permitting natural mobile scrolling. Motion respects prefers-reduced-motion.

03 / DESIGN

THE SIGNAL.

A big statement catches your eye. Color helps you choose. Motion explains what changed. The graphics have a job before they have a style.

Explore the mechanics ↗

Design tokens: charcoal, paper, petrol, sage, clay, ochre and constrained bright functional accents. Typography uses Bricolage Grotesque, Manrope and IBM Plex Mono, with local system fallbacks. Icons are inline SVG. The hero includes a cutout with transparent alpha.

04 / ENGINEERING

THE MACHINE.

The site is intentionally simple to host. The experience is written in HTML, CSS and JavaScript. The expensive-looking part doesn't require an expensive backend.

Explore the mechanics ↗

Frontend: static HTML + responsive CSS + native JavaScript, with no mandatory JS framework. One optimized WebP hero asset. Data-driven focus selection changes text and links deterministically. GitHub Pages supports current deployment and a custom domain later. Source remains portable to other static hosts.

05 / AI

THE ASSIST.

AI helped structure this experience. But a visitor shouldn't have to trust a chatbot to see trustworthy evidence. The selected proof comes from defined project information.

Explore the mechanics ↗

ChatGPT-assisted research, interface/content drafting and development. The interactive lens is pre-authored and operates in the browser; it does not call a model or generate live claims. Any future live AI integration requires a secured server endpoint, privacy controls, an evidence registry and explicit disclosure.

06 / DELIVERY

THE RELEASE.

The job isn't done when the design looks right. Links, responsiveness, touch, accessibility and reliable deployment are part of the product.

Explore the mechanics ↗

Acceptance: click/hover/focus states, four focus options, scroll-triggered sequential 3D turn, reduced-motion fallback, mobile widths 320px+, no horizontal overflow, preserved CV and work paths, deployment verification. Next: on-device field performance and accessibility audit.
